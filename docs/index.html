Política de Privacidade do CadastroPorVoz

Última atualização: 30 de julho de 2026.

O aplicativo CadastroPorVoz foi desenvolvido para permitir o cadastro de pessoas por meio de formulário e reconhecimento de voz, com armazenamento local e sincronização segura.

1. Dados coletados

O aplicativo pode armazenar os seguintes dados informados durante o cadastro:

  • nome;
  • endereço;
  • telefone;
  • observações;
  • data e horário do cadastro ou alteração;
  • identificação do usuário responsável pelo registro.

Para autenticação, o aplicativo pode receber do provedor de login o nome público, o identificador da conta e outras informações básicas autorizadas pelo usuário.

2. Uso dos dados

Os dados são utilizados exclusivamente para realizar, consultar, editar, sincronizar e auditar os cadastros feitos no aplicativo.

3. Login com Google

O CadastroPorVoz permite autenticação por e-mail e senha, Google. O aplicativo não recebe nem armazena as senhas utilizadas nessas plataformas.

A autenticação é processada pelos respectivos provedores e pelo Firebase Authentication.

4. Armazenamento e segurança

Parte dos dados pode ser armazenada localmente no dispositivo e sincronizada com o Firebase Firestore.

O acesso ao banco de dados é protegido por autenticação e regras de segurança.

5. Compartilhamento de dados

Os dados não são vendidos. Eles não são compartilhados com terceiros para fins de publicidade.

Os dados podem ser processados pelos serviços necessários ao funcionamento do aplicativo, como Firebase, Google e Meta.

6. Exclusão de dados

O usuário pode solicitar a exclusão dos dados associados à sua conta entrando em contato com o responsável pelo aplicativo.

A solicitação deve informar o e-mail ou a conta utilizada no login, para que os dados possam ser identificados.

7. Contato

Para dúvidas, correções ou solicitações de exclusão de dados, entre em contato pelo e-mail:

jribeiro@ufu.br

8. Alterações nesta política

Esta política poderá ser atualizada para refletir mudanças no aplicativo, nos serviços utilizados ou nas exigências legais.
